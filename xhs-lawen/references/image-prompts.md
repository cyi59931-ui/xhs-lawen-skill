# 人物剧照风配图提示词（统一视觉）

> 账号配图基调固定：**高质感名人/人物剧照 + 新闻抓拍/杂志大片感**，突出"眼神聚焦、强大从容"的高级感。

## 一、统一风格基底（每张都带的"底盘"）

```
电影质感人物剧照/杂志封面大片风格；强对比光影，背景干净或景深虚化；
主体为一位自信、从容、眼神聚焦有力的女性，姿态挺拔有掌控感；
色彩高级（低饱和深色调+高光点睛，或暖金黑调），画面有呼吸感与留白；
质感如时尚杂志 editorial / 新闻光纪实大片，非低俗网红滤镜、不过度磨皮、不白瘦幼。
```

## 二、按内容类型切换子风格

| 模板 | 子风格关键词 |
|---|---|
| A 单人物赏析 | 人物半身/全身剧照，逆光或侧光，眼神坚定"定力感"，极简高级背景 |
| B 顶配权贵/体制 | 正装/制服/权力感构图，庄重外交/王室/职场大片，冷色高级感 |
| C 体育燃点 | 动态运动抓拍，赛场光影，汗珠/锐利目光/破纪录瞬间的张力 |
| D 冷门传奇/历史 | 复古胶片/旧时代质感，年代服装，倔强而坚定的眼神，历史厚重感 |
| E 观点热点 | 意象化戏剧构图（对比画面/讽刺符号），或人物特写+深刻目光 |
| F 方法论/干货 | 干净利落的杂志排版感，人物自信姿态+可配步骤符号，清爽有设计感 |

## 三、构图与版式

- 竖版 3:4 / 4:5（小红书友好）。
- 封面：标题大字（简洁现代无衬线/衬线大字，白字压深色调/暗部），呼应"闪耀女性"高级感。
- 分段：每段一个人物成长节点/状态视觉，动作构图承载该段观点（如"宣誓""绝杀""舞台""法庭"）。
- 每篇 4-8 张：封面 1 + 每段 1。
- **同人不同阶段对比**（A 模板成长节点）：同一人物轮廓，只改服装/场景/光影（青涩→巅峰），像"一套人物成长剧照"，读者一眼看懂"她把苦难渡成了底气"。

## 四、负面词（必带）

```
不要：网红滤镜、过度磨皮、大眼高鼻尖下巴网红脸、白瘦幼、露骨低俗、AI 拼贴感、
西方刻板印象（除非选题就是）、把真实名人画歪或丑化——统一保持高级剧照/电影质感。
```

## 五、调用姿势（baoyu-image-gen）

```bash
bun {baoyu-image-gen 的 SKILL.md 目录}/scripts/main.ts \
  --prompt "〈统一基底+子风格+主题视觉+负面词〉" \
  --image "output/封面.png" --ar 3:4 --quality 2k
```

- 多张可写 batch JSON 一次批量出图。
- **未配 API key**：照样给每张完整提示词与设计，说明需 key 才能出图，供用户自行生成或稍后提供 key。
