# 固定元素库（句库 / 公式库 / 标签库 · 直接取用）

> 从「鲜评辣雯」30 篇真实笔记提炼的"可无脑复用"元素。写任何模板都从这里取。

## 一、账号人设与姿态

- "收集世间闪耀女性，不谈年龄，只论自我。"（账号简介，可作开场/落款点题）
- "我那一票，永远留给【人物】。"——有明确立场的欣赏者。
- "如果你看腻了……，那一定要认识……现实中这位……"——推荐者姿态。
- 不批评、不站队，只做"把这些厉害女人的故事讲给你听"的引路人。

## 七、红线（所有模板遵守）

- 不消费/丑化真实人物——写真人保持尊重，聚焦其精神内核与成就，不编造惊艳细节作为道德污点的猎奇。
- 关键事实有据，存疑用"主流说法/据报道/曾"，不把人物当爽文瞎编。
- 不贩卖焦虑本身——写"被低估、年龄、容貌"等时，结尾必须落到"守住内心秩序/把价值放回自己"的正面力量。
- 配图保持高级剧照/新闻质感，不用低俗猎奇或过度 P 图网红脸。
- 聚焦单个女性（或明确群像），不借机踩其他群体/男性来立"恶女"对立——就算写"恶女天花板"（如泽尻），也强调其生命力与敢于担当，而非鼓励堕落。
