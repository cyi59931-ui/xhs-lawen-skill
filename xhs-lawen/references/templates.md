# 六类通用模板 · 完整骨架与写法

> 从「鲜评辣雯」30 篇真实笔记逐篇归类。每类含：骨架、每个板块怎么写、真实笔记的例分解读（标题做注）、可复用句式。

## A. 单人物"大女主"赏析型（账号绝对主打）

**最稳爆款公式**：一位具体女性人物 × 固定"普通人 vs 她"对照 × 成长节点 × 入场券金句。

**骨架**：
```
[开头]
  时代横行："在这个流行精致人设、小心翼翼迎合的【领域】里……"
  + 人物定调："如果要在【领域/群体】里选出一位【特质】到极致的女性，我的那一票，永远留给【人名】。"
[中段]
  1️⃣ 起点/身份（出身、出道、背景）
  2️⃣ 至暗时刻（被低估/网暴/换角/偏见——"普通人早就写满一脸怨气与苦相"）
  3️⃣ 她把苦难渡成底气（死磕/专注/把受过的伤当滤网）
  4️⃣ 巅峰/成就（奖项/纪录/逆袭封神）
  每段都用"外界扔过来的偏见，别人接住了烂在心里变内耗；而她，看一眼、放过去，绝不留一丝痕迹"式的对照。
[收尾]
  入场券金句："长得漂亮只是入场券，踢得够狠、活得够飒、随时输得起才算真本事。"
  + "轻舟已过万重山，属于她的时代，才刚拉开序幕。" + 互动"你最被她哪个瞬间圈粉？"
```

**真实例解**（标题即证）：恭喜杨紫！从"不适合当演员"到白玉兰视后 / 鲁豫 年过50仍稳坐访谈顶级牌桌 / 吴越的松弛感，是中年最硬核的顶级磁场 / 董明珠｜突然来到了"有牌可打"的年纪 / 我不怕老，我只怕僵硬（叶童）/ 我不打算停下来（张曼玉）。

**可复用开头**："很多人对她的记忆，还停留在【旧标签】。但如果你仔细看完她的人生轨迹，就会发现，她是【领域】最清醒的野心大女主。""直到今天，依然有很多人以为……但你如果只知道【这一点】，就太低估这个女人了。"

## B. 顶配权贵 / 体制型

**骨架**：
```
[开头]
  顶配起点对比："同样【年龄】，普通女孩在【享受青春】，而【主角】早已手握【王位/权力/豪门】，身披……"
  + 落差揭晓："但不同于大众印象中养尊处优的【身份】，她的人生从无躺平可言。"
[中段]
  1️⃣ 顶配起点（出身/册封/豪门，生来就站在人生顶配起点）
  2️⃣ 从小最高标准培养（打破娇养模式/送平民学校/专属课程，拒绝特殊待遇）
  3️⃣ 硬核自律细节（集体宿舍/清晨出操/高强度训练——"最不娇气的继承人"）
  4️⃣ 布局自我/成就（领域跨界/斩获荣誉/不信命）
[收尾]
  "真正的【高贵】，从不是与生俱来的身份，而是严于律己的自律、负重前行的担当、永不懈怠的成长。"
  + "她证明了【她】不靠【身份】，而是靠【内核】。"
```

**真实例解**：生来是公主，苦练成女王，20岁戎装加身（莱昂诺尔）/ 顶配颜值+硬核智商：厄瓜多尔第一夫人 / 那个金发超模脸（克洛伊·凯莉）里的豪门视角。

**可复用开头**："生来就站在人生顶配起点，却……""在这个流行白富美和网红名媛的时代，她用实际行动告诉全世界：长得漂亮只是入场券，有脑子、够狠，才是王牌。"

## C. 女性体育燃点型

**骨架**：
```
[开头]
  力量美 / 绝对统治力切入："最近疯狂刷屏、给所有中国女孩狠长长脸的，绝对是【运动员】。"
  或反差："她拥有最甜美的神颜，却在【赛场】留下了最狠的绝杀。"
[中段]
  1️⃣ 背景/横空出世（年龄、身份、起点）
  2️⃣ 关键一战/破纪录（"一投定乾坤/第一投直接锁死冠军/替补111秒绝杀"）
  3️⃣ 伤病与坚持（生理期、带伤、训练血泪——"普通人早就焦虑自我拉扯"）
  4️⃣ 精神内核（天生带"精神过滤器"/把痛感过滤掉，聚焦赛场）
[收尾]
  "长得漂亮是她的优势，但踢得够狠、活得够飒、随时输得起才是她的本事。"
  + "她不需要任何人来定义她的性感/力量，她就是最高级的标签。"
```

**真实例解**：一张还没褪去婴儿肥的脸，有着初代权力感（严子怡标枪）/ 一脚点球把男足都干沉默（克洛伊·凯莉）/ 哈萨克斯坦的神颜天花板（跳高新星贾斯敏）/ 站上顶峰，女性体育人的热血与倔强（群像）。

**可复用开头**："在这个崇尚精美人设和小心翼翼计算卡路里的时代，她的出现，就像一道划破长空的【利器】，向全世界展示了什么叫顶级力量美与硬核大女主。"

## D. 冷门传奇 / 被误解型

**骨架**：
```
[开头]
  传奇身份揭晓："她是【历史中第一/唯一】的【身份】，也是被【时代】长久误解/埋没的女性。"
  + 金句立人："我演了无数次死掉的角色，但我的一生，从未认输。"
[中段]
  1️⃣ 被时代绑定的身份（种族/性别/标签/童星的枷锁）
  2️⃣ 遭遇的剥削与误解（"两头不讨好/被当玩偶/被资本计算"）
  3️⃣ 破局与抗争（只身远赴/跨界转型/死磕到底掀翻棋盘）
  4️⃣ 迟到的致敬（历史最终承认/成就长青）
[收尾]
  "她曾活成受害者，但她最终是真正的破局者。"
  + "岁月从不败深耕者，守住内心的秩序，你就永远在顶配牌桌上。"
```

**真实例解**：被好莱坞剥削，被母国误解（黄柳霜）/ 如果可以，我希望自己从未当过童星（秀兰·邓波儿）/ 我以为自己从未后悔（梁洛施）/ 金庸笔下的小龙女原型（夏梦）。

**可复用开头**："在【时代】那些【枷锁】盛行的年代，一个【出身】的女孩，生生凭借一张【特质】的面孔/韧劲，在【领域】杀出了一条血路。"

## E. 观点评论 / 社会热点型

**骨架**：
```
[开头]
  抛出热点/对比："现在看【A】和【B】的对比，真的挺讽刺的。"
[中段]
  1️⃣ 拆解 A 的"真/值"（高能量/真诚/治愈）
  2️⃣ 拆解 B 的"假/坑"（偷换概念/情怀刺客/信息差变现）
  3️⃣ 上升到社会情绪与价值观（年轻人的需求/被戳中的痛点）
[收尾]
  清醒金句："做生意，真诚才是必杀技。在这个人人精神内耗的时代，我们愿意为真正的快乐买单，但绝不接受用情怀当幌子的欺骗。"
  + "真正触动我们的，从来不是阶层/标签，而是普通人都能共情的人生真相。"
```

**真实例解**：为"情绪布施"买单，拒绝"情怀背刺"结局（鸡排哥vs鹅腿阿姨）/ 模特老了怎么办？（奚梦瑶婚礼vs晚晚回旋镖）。

**可复用开头**："在这个人人【紧绷/精神内耗】的时代，我们不是傻，我们愿意为【真正的价值】买单，但绝不接受【虚假的情怀/滤镜】。""这场时隔N年的回旋镖，最动人的从来不是【表面的差距】，而是普通人都能共情的人生真相。"

## F. 方法论 / 成长干货型

**骨架**：
```
[开头]
  抛出痛点："你从不是能力不行，是【懦弱的表达/自我矮化】硬生生困住了本该亮眼的自己。"
[中段]
  1️⃣ 戳破误区（"你可能以为……其实……"）
  2️⃣ 借真实榜样点破（如杨澜/鲁豫的关键不在于话术圆滑，而在敢握住主动权）
  3️⃣ 落地心法 N 步（1️⃣2️⃣3️⃣ 每步给可复制的动作/句式）
[收尾]
  "真正的好好说话/成长，不是变得咄咄逼人，而是跳出自我内耗，把自身价值放回本该拥有的位置。"
  + 互动"你中招了吗？评论区聊聊。"
```

**真实例解**：一开口就被人小看？真不是你没能力（杨澜表达心法）/ 野心女人？Why not you（能量显化）。

**可复用开头**："你从不是【能力不足】，是【一个具体习惯】困住了本该亮眼的自己。""明明【做事靠谱】，可一到【关键场合】就【自贬】。辛辛苦苦的成果，却总被隐形。"
