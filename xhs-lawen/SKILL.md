# 女性力量 × 大女主人物志 · 图文笔记生成器（通用模板）

> 从「鲜评辣雯」账号 **30 篇真实笔记**逐篇归类，提炼成 **6 类可复用通用模板**（模板A-F）。
> 用户给主题后，本 skill **自动判断最适合的模板类型并套用其骨架**，产出同赛道图文笔记（正文 + 配图）。
> 核心公式：**一个闪耀女性/主题 × 一个模板骨架 × 一段"普通人 vs 她"对照 × 一句入场券金句 × 收尾升华 + 话题标签矩阵**。

## 一、固定底色（所有模板通用，先建立再套用）

**账号立场**：一个"收集世间闪耀女性"的观察者。不谈性别对立、不批评哪个群体，只聚焦**单个鲜活女性**如何靠内核/定力/死磕，在残酷世界里守住内心的秩序。一句话概括：**用一个个真实女性的故事，证明女性的力量、清醒与高级感**。

**语气习惯**（写每篇都带）：
- 对人物：直呼其名/尊称，带着"顶礼膜拜的欣赏"口吻："她太懂社会的规矩了，但她偏要用……去重塑属于她的规则"。
- 对读者：第二人称"你/女孩子/普通女孩"，制造参照与代入："普通人面对这样的打击，可能早就写满了一脸怨气与苦相；但……"
- 口语化连接词："你要知道 / 很多人不知道 / 更让人动容的是 / 回看……"。

**核心母题金句库（句末必取其一）**：
- "长得漂亮只是入场券，有脑子、够狠，才是新时代大女主的王牌。"
- "踢得够狠、活得够飒、随时输得起，才算真本事。"
- "懂社会的规矩，但偏不遵守；守住内心的秩序，你就永远在顶配牌桌上。"
- "轻舟已过万重山，属于她的清贵与时运，才刚刚开始。"
- "理想的人生，不是去迎合别人的审美，而是守住内心的秩序，守住这份清贵。"
- "大女主的底牌，从来不是迎合，而是掌控。"

**人物精神词汇库（贯穿所有模板，描写人物内核必用）**：
- 高维磁场 / 精神过滤器 / 钝感力 / 内部秩序感 / 定力 / 松弛感 / 聚焦 / 清澈
- "看透红尘黑白后，依然选择死磕专业的'天真'"
- "天生自带一个'过滤器'，别人扔过来的消耗，她看一眼、放过去，绝不留一丝痕迹"
- "主动选择的单纯，反哺到面相上就成了超然物外的干净"
- 智性恋 / 顶配 / 大女主 / 不被定义 / 本门本户 / 掌控力

**互动引导（句中/结尾必带其一）**：
- 共鸣式："你是不是也曾被这样低估过？评论区聊聊。"
- 升华式："愿你也像她一样，守住这份清贵。"
- 人物死磕式："你最被她哪个瞬间圈粉？评论区告诉我。"
- 收藏钩子："收藏这篇，等低谷时翻出来给自己打气。"

**排版**：小红书格式，短句、大量换行、emoji 分区（2-6 个内），`1️⃣2️⃣3️⃣` 编号主导读（人物成长节点常按时间线/阶段编号），配图位置用 `【配图n】` 标注。

**话题标签（8-15个）**：
- 常驻：#女性力量 #女性能量 #女性崛起的力量 #女性影响力 #女性自信的力量 #女性能量显化 #不被定义 #自信与优雅 #女性她力量 #致敬她力量
- 题材追加：#体育魅力 #大女主 #智性恋 #女性成长 #女性领导人 #历史人物 #名人故事 #女性身份认同（按人物/题材追加）

## 二、模板选择（Step 1）——六选一

用户给主题后，按内容性质**自动选最契合的模板**（也可直接问用户想要哪类）：

| 模板 | 名称 | 最适合的选题 | 占比 |
|---|---|---|---|
| **A** | 单人物"大女主"赏析型 | 一位具体女性人物的成长/成就/逆袭，套用固定"普通人vs她"对照（**绝对主打**） | 主打 |
| **B** | 顶配权贵/体制型 | 公主/第一夫人/豪门千金（天生顶配但仍硬核自律） | 常做 |
| **C** | 女性体育燃点型 | 刚爆火的女性运动员/体育集体的力量美与热血 | 常做 |
| **D** | 冷门传奇/被误解型 | 被时代误读、被剥削或埋没的女性，用一生抗争/破局 | 常做 |
| **E** | 观点评论/社会热点型 | 一个当下话题/热点事件的辛辣、清醒点评 | 撑打开率 |
| **F** | 方法论/成长干货型 | 给普通女性的可执行成长/表达方法论 | 撑收藏 |

用户不给主题 → 从 `references/topics.md` 选题池自动挑 1 个并告知选了哪个。

**选题质检（HKR），不过关就调方向**：
- **H**：标题让人想收藏/点赞，有"被戳中"或"想认识这个厉害女性"的吸引。
- **K**：看完能"认识一个真实女性的高光/成长/内核"，有一句能记住的金句。
- **R**：让读者"对对对，我也想活成这样/想被她激励"。

## 三、按模板生成正文（Step 2）

> 详细骨架与每类写法见 `references/templates.md`，这里是速查。

- **A 单人物大女主赏析**：时代横行开篇 → "普通人vs她"对照 + 人物精神词汇（过滤器/钝感力/定力） → `1️⃣2️⃣3️⃣` 成长节点（童星出道/至暗时刻/逆袭封神） → "入场券"金句收尾 + 互动。
- **B 顶配权贵体制型**：顶配起点 ≠ 躺平 → 从小最高标准培养 → 硬核自律细节 → "最不娇气/主动选择的使命"升华。
- **C 体育燃点型**：用力量美/绝对统治力切入（"一投定乾坤/一脚点球把男足干沉默"） → 关键一战/打破纪录 → 伤病与坚持 → "踢得够狠活得够飒"金句。
- **D 冷门传奇被误解型**：被时代绑定的身份/标签 → 一生抗争与破局 → 历史迟到的致敬 → "她不是受害者，是破局者"升华。
- **E 观点热点评论型**：抛出热事件/对比 → 辛辣拆解"真/假、值/坑" → 落到社会情绪/价值观 → 清醒金句。
- **F 方法论干货型**：抛出一个痛点 → `1️⃣2️⃣3️⃣` 可执行心法 → "把价值放回本该属于你的位置"收尾。

## 四、配图（Step 3）

基调固定：**高质感名人/人物剧照风**（杂志大片/新闻抓拍质感，强对比光影，主角强大从容的"眼神聚焦"感）。每篇 **4-8 张**竖版（3:4 / 4:5）。
- 封面：标题大字（简洁现代无衬线/衬线大字，白字压深色调），呼应"闪耀女性"高级感。
- 分段：每段一个人物成长节点/状态视觉，动作构图承载该段观点。
- 详细 prompt 见 `references/image-prompts.md`。
- 生成用 `baoyu-image-gen` skill（需用户已配 API key）。**未配 key** → 照常给每张完整提示词与设计，说明需 key 才能出图。
- 多张可用 batch JSON 一次批量出图。

## 五、交付清单

1. **模板选择**：用的是哪类模板（A-F）+ 为什么。
2. **标题**：1-3 个候选（反差/认知/致敬型）。
3. **正文**：小红书格式 + 话题标签 + `【配图n】` 标注。
4. **配图**：每张视觉方案 + 提示词（已出图则给路径）。
5. **一句话自检**：是否落到"女性力量/守住内心秩序"内核 + 是否带互动引导 + 是否有可记忆金句。
